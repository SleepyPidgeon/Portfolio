Build Ver 0.0.1

To get started with this detector the database using SQLite3 must be created by running the setup_db.py file.. This will create the table that will store the information
generated by the mock generator.

Run mock_generator.py in a terminal, to end the generation of information use ctrl+c

Now the fun part, information can be displayed using one or both of the application developed.

First is the application dashboard development using Streamlit, to run this python code enter python -m streamlit run app_dashboard.py in a new terminal with the directory
pointed to the project folder.

Second to run is much more simple, the radarview developed using Pygame can be opened in the terminal with just python radarview.py of course with the terminal directory
pointing to the project folder.
